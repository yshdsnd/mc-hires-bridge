# v0.2.0

Music Center for PCのDirectSound（共有）で、DSEE HXとハイレゾFLACを利用しやすくしました。

## 主な変更

- DSEE HXを共有出力で利用可能にしました。44.1／48 kHzの対応ステレオ音源を24 bitで出力します。
- HR-BRの右クリックから2倍（88.2／96 kHz）と4倍（176.4／192 kHz）を選択できます。初期値は2倍で、選択は再起動後も保持されます。
- 再生中のDSEE HX切り替えは次に新しく開く曲から適用し、途中OFFで発生していた強いノイズと再生位置の飛びを修正しました。先読み済みの次曲は準備済みの設定で再生します。
- 異なる形式への自動曲送りで前曲の末尾を保持する処理を統合しました。
- HR-BRのツールチップに入力形式・処理経路・DirectSoundへの出力形式を表示します。
- 対応する48／96／192 kHz・24 bitのステレオFLACは、元のレートと24 bitを維持してDirectSoundへ渡します。
- 配布READMEを機能と操作中心に整理しました。

## 利用方法と対応範囲

ZIPを展開し、MC HiRes Bridge.exeを起動してください。更新時はMusic Centerを完全終了してからファイルを入れ替えてください。

Windows 11、Music Center for PC 2.7.4（32 bit、標準インストール先）で確認しています。WAV・DSDのハイレゾ原音形式維持は対象外です。DirectSoundに渡す形式と、Windows共有ミキサーを通過したデバイス側の形式は異なる場合があります。

倍率サブメニューでEscを押すと、Music Centerが一覧へ戻ってメニューが残る場合があります。領域外クリックで閉じてください。

詳細は[利用ガイド](https://github.com/yshdsnd/mc-hires-bridge/blob/v0.2.0/docs/package-readme.md)を参照してください。
